# 设计约定

项目采用个人私有案例库模型：一个案例包含多个实验版本，每个版本独立保存提示词、供应商、模型、参数备注、效果笔记与三段代码。最佳版本决定画廊上的模型展示。

视觉基于 `concept.png`：背景 #111315，面板 #191c1f，边框 #2b3033，主操作 #b5f3cf；左侧导航，右侧三列效果画廊；编辑页左侧记录、右侧代码和预览。字体使用本机无衬线字体回退，避免外部字体请求成为加载依赖。编辑器延迟加载。手机画廊为单列，导航收起，编辑表单和工作区纵向排列。

概念到实现的必要调整：模型标签使用真实记录；内置案例标为“内置示例 / 手工演示”；增加版本数、更新日期、排序、账号退出与备份入口；表单包含明确要求的版本、封面和导出功能，长度超过概念图。封面是示例代码效果的静态表现，首页不运行用户代码；上传封面后替换静态默认封面。

概念由内置 Image Gen 生成。提示要求：深色中文 Prompt Gallery，个人 AI 前端提示词与效果库；完整画廊和编辑器两个画面；薄荷绿操作，细边框，清晰文字，三列效果卡片，左侧导航、搜索、模型筛选与标签；编辑器含提示词、模型、HTML/CSS/JavaScript 和运行预览，不添加营销版块或虚构统计。

运行方式采用单进程 Node + SQLite，管理员密码使用 scrypt，登录 cookie 仅供服务端会话验证。案例写入带 revision，拒绝覆盖其他设备新保存的版本。备份合并在事务中完成，导入只影响案例，不包含账号。
